# Introduction 
This folder will contain scripts and information related to load testing DVT.  
Currently, we are using LOCUST to unit test. Locust is an open-source load testing tool that uses scripts written in Python to perform a variety of load test scenarios on APIs and websites.

# Pre-requisites
1. Visual Studio Code
2. Python 3
3. Python Debugger Extension for VS Code. [Link](https://marketplace.visualstudio.com/items?itemName=ms-python.debugpy)
4. Python Extension for VS Code. [Link](https://marketplace.visualstudio.com/items?itemName=ms-python.python)
5. Python Environments Extension for VS Code. [Link](https://marketplace.visualstudio.com/items?itemName=ms-python.vscode-python-envs)
6. Locust

# Getting Started
1. Install the pre-requisites
2. Follow the Getting Started instructions in the main documentation (see link below)
3. Create your first script and try it out!
